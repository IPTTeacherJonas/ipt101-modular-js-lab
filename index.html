Modular JavaScript Student Profile with Git & GitHub

Objective: Students will build a modular student record system using core JavaScript features—structuring their personal profile as an object (id, name, program, yearLevel, schoolYear), implementing functions with parameters, object methods with arguments, and ES6 modules—while practicing version control by organizing, documenting, and pushing their work into a dedicated subfolder within their Main GitHub Repository.

// studentDirectory.js

const studentRecord = {
  name: "Your Full Name",
  id: 0000,
  program: "Your Program",
  yearLevel: "Your Year Level",
  schoolYear: "2026-2027",

  getEnrollmentDetails(semester, campus) {
    return `[${this.schoolYear} | ${semester}] Student ${this.name} (ID: ${this.id}) from ${this.program} (${this.yearLevel}) is registered at ${campus}.`;
  }
};

console.log(studentRecord.getEnrollmentDetails("1st Semester", "Main Campus"));

Local Workstation Instructions:

  • Create studentModule.js to export your studentDetails object and a printSummary(student, status) helper function.

File 1: studentModule.js

Reference (Copy Disabled) 
// studentModule.js

export const studentDetails = {
  name: "Your Full Name",
  id: 0000,
  program: "Your Program",
  yearLevel: "Your Year Level",
  schoolYear: "2026-2027"
};

export function printSummary(student, status) {
  return `Student: ${student.name} | ID: ${student.id} | Program: ${student.program} | Status: ${status}`;
}

File 2: mainApp.js

Reference (Copy Disabled)

import { studentDetails, printSummary } from './studentModule.js';

const enrollmentMessage = printSummary(studentDetails, "Officially Enrolled");
